# .aliases

Коллекция bash/zsh функций и алиасов для автоматизации часто используемых операций при разработке. Включает инструменты для работы с Git, Docker, Python проектами и архивацией файлов.

## Требования

Для полноценной работы всех функций необходимы следующие инструменты:

- git + git flow
- zstd, lz4
- zip, unzip
- tmux
- xclip
- lvim
- pyenv
- docker
- poetry

## Установка

Добавьте следующий код в ваш `.bashrc` или `.zshrc`:

```bash
# Подключение алиасов из отдельной папки
for file in ~/.aliases/*.sh; do 
    [ -r "$file" ] && . "$file"
done
```

## Функции и алиасы

### Git и Git Flow

#### fs - Создание новой ветки
Автоматически определяет префикс проекта и следующий номер ветки.

```bash
fs  # Создаст ветку feature/PREFIX-N, где N - следующий номер
```

#### ff - Завершение ветки
Автоматизирует процесс завершения feature-ветки:
- Проверяет статус изменений
- Создает коммит через commitizen
- Завершает ветку через git-flow
- Отправляет изменения в репозиторий

```bash
ff  # Находясь в feature-ветке
```

#### release - Создание релиза
Автоматизирует процесс создания релиза:
- Определяет следующую версию
- Создает changelog
- Создает теги
- Отправляет изменения в репозиторий

```bash
release  # Запустит процесс создания релиза
```

#### init-python-project - Инициализация Python проекта
Создает новый Python проект с настройкой:
- Git и Git Flow
- Виртуального окружения через pyenv
- Poetry для управления зависимостями
- Commitizen для стандартизации коммитов
- Базовых инструментов разработки (ruff, pytest, black, isort)

```bash
init-python-project  # Запустит интерактивный процесс создания проекта
```

### Docker

#### up - Запуск контейнеров
```bash
up  # Запускает все сервисы
```

#### down - Остановка контейнеров
```bash
down  # Останавливает все сервисы
```

#### restart - Перезапуск контейнеров
```bash
restart  # Перезапускает все сервисы
```

#### logs - Просмотр логов
```bash
logs  # Показывает логи всех контейнеров
```

#### Дополнительные команды
- `local-api` - Запуск только API контейнера
- `local-bot` - Запуск только бота
- `local-celery` - Запуск только Celery worker
- `build` - Сборка образов

### Python разработка

#### lint - Проверка кода
Запускает линтеры (ruff, mypy) для указанных директорий:
```bash
lint  # Проверит текущую директорию
```

#### lint-fix - Автоисправление проблем
Автоматически исправляет проблемы форматирования:
```bash
lint-fix  # Исправит проблемы в текущей директории
```

#### test - Запуск тестов
```bash
test  # Запускает pytest
```

#### clean - Очистка временных файлов
Удаляет:
- `__pycache__`
- `.pyc`, `.pyo`, `.pyd` файлы
- Кэш pytest и mypy
```bash
clean
```

#### update-deps - Обновление зависимостей
```bash
update-deps  # Обновляет зависимости через poetry
```

#### revision - Создание миграции
```bash
revision  # Создает новую миграцию alembic
```

### Архивация

#### Работа с tar
- `tarx` - Распаковка tar архива
- `tarc` - Создание tar архива

#### Работа с zstd
- `zc` - Сжатие файла
- `zdc` - Распаковка файла

#### Работа с lz4
- `lzc` - Сжатие файла
- `lzd` - Распаковка файла

#### Работа с zip
- `zipf` - Создание zip архива
- `unzipf` - Распаковка zip архива
